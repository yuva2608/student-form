# 🎓 Student Data Form Using JavaScript

## 📌 Project Description

The **Student Data Form** is a simple and interactive web application developed using HTML, CSS, and JavaScript. It allows users to enter student details through a form and displays the submitted data on the webpage.

This project helps beginners understand form handling, DOM manipulation, event listeners, and JavaScript validation.

## ✨ Features

- 📝 Enter student details through a form.
- 👨‍🎓 Collect student name, roll number, age, email, phone number, and department.
- ✅ Validate user inputs using JavaScript.
- ⚡ Handle form submission using event listeners.
- 📋 Display submitted student details dynamically.
- 🎨 Simple and user-friendly interface.
- 📱 Responsive design (if implemented in CSS).

## 🛠️ Technologies Used

- **HTML5** – Structure of the form.
- **CSS3** – Styling and layout.
- **JavaScript** – Form validation, event handling, and DOM manipulation.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Enter the student details in the form.
5. Click the Submit button to view the result.

## 📋 Student Details

The form can include the following fields:

- Student Name
- Roll Number
- Age
- Email Address
- Phone Number
- Department
